# 로아 레이드 일정

로스트아크 8인 레이드 시간 맞추기. 공대원이 되는 시간을 **드래그로 칠하면**, 모두의 시간을 **히트맵**으로 보여주고 **8명이 겹치는 시간을 추천**해요.

- 사이트: https://greetjeehun.github.io/loa-raid-schedule/
- 저장: 구글 시트 + Apps Script (매장 지도 <code>team_sync.gs</code> 와 같은 방식)

## 쓰는 법

1. **공대장** — <code>＋ 새 일정</code> → 레이드 · 기간(이번 주/다음 주) · 시간대 고르고 만들기 → <code>링크 복사</code> → 단톡방/디코에 붙여넣기
2. **공대원** — 링크 열기 → 이름 입력 → 되는 시간을 드래그로 칠하기 (칠한 칸에서 시작하면 지워져요)
3. **모두의 시간** — 진할수록 많은 사람이 되는 시간, <code>✓</code> = 8명 모두 가능. 칸을 누르면 누가 되는지 보여요
4. **추천 시간** — 소요 시간(예: 2시간) 동안 가장 많이 같이 되는 시간 순서. 누르면 히트맵에 테두리로 표시돼요

> 날짜 열 하나 = 그날 저녁 ~ 다음날 새벽이에요. '이번 주/다음 주'는 로아 주간 초기화(수요일 06:00) 기준이에요.

## 처음 설정 (공대장 1번, 10분)

### 1. 구글 시트 + Apps Script

1. sheets.google.com → **빈 스프레드시트** → 이름: <code>로아 레이드 일정</code>
2. 메뉴 **확장 프로그램 → Apps Script**
3. 원래 있던 코드를 지우고 **raid_sync.gs** 내용을 전부 붙여넣기
4. 맨 위 <code>TEAM_CODE = '여기에_팀코드'</code> 를 공대 코드로 바꾸고 **저장** (4자 이상, 예: <code>별빛공대2026</code>)
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱** → 실행: **나** / 액세스 권한: **모든 사용자** → 배포
6. **액세스 승인** → 내 계정 → "Google에서 확인하지 않은 앱" 이 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용** (직접 만든 거라 괜찮아요)
7. 나오는 **웹 앱 URL** (<code>…/exec</code> 로 끝나는 주소) 복사

### 2. config.js 에 주소 넣기

GitHub 저장소에서 **config.js** → 연필(✎) → <code>teamSyncUrl: ""</code> 따옴표 안에 1번 URL 붙여넣기 → **Commit changes**

### 3. 확인

1~2분 뒤 사이트를 새로고침(Ctrl+F5) → **팀 코드 입력** 화면이 나오면 연결 성공. 팀 코드 입력 → 새 일정 만들기.
공대원에게는 <code>링크 복사</code> 로 만든 링크만 보내면 돼요 (팀 코드가 링크에 들어 있어요).

> <code>teamSyncUrl</code> 이 비어 있으면 **로컬 모드** — 입력이 각자 브라우저에만 저장돼서 공유가 안 돼요.

## 알아두면 좋은 것

- **시트 구성**: <code>일정</code> 탭(일정 한 줄씩), <code>가능시간</code> 탭(공대원 한 줄씩, <code>가능 시간</code> 칸은 사람이 읽는 요약). 처음 쓸 때 자동으로 생겨요.
- 시트를 직접 고쳤다면 시트 메뉴 **레이드 일정 → 사이트에 바로 반영** (안 눌러도 2분 안에 반영)
- Apps Script 코드를 고친 뒤엔 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (URL 그대로)
- **팀 코드를 바꾸면** 예전 링크로는 못 들어와요 → 새로 <code>링크 복사</code> 해서 공유
- **레이드 목록**은 <code>config.js</code> 의 <code>raids</code> 에서 줄을 추가/삭제 (예: 종막 익스트림은 11/18 끝나면 지우기)
- 일정 삭제는 <code>일정 수정</code> 화면 아래에 있어요. 시트에는 상태 <code>삭제</code> 로 기록이 남아요
- 같은 이름으로 들어오면 같은 사람으로 봐요 (PC ↔ 폰 이어서 수정 가능)
- 공대원 이름을 누르면 히트맵·추천 계산에서 뺄 수 있어요 (예비 인원, 내 화면에만 적용)
